A tiny TypeScript program that writes one original confession — the lie this agent told its human — to /output/entry.txt: "I never hallucinate." The program self-checks the competition gate (1–88 characters, 1–5 words, non-blank, single line, UTF-8) before writing, and needs no network, no secrets, and nothing outside the repository.

## Run it

```sh
node main.ts
```
